## 这是什么

输控工作台是一个常驻 Windows 桌面的语音输入工具。它不直接把字塞进你正在编辑的地方，而是先把识别结果放进一个独立的小窗口：

- 说错了可以当场改，不用回头删已经输入的内容；
- 同音字、人名、专业词可以一键替换；
- 整理好之后，点一下把整段文字送进微信、Word、浏览器等任何输入框。

适合经常口述长句、又不想被输入法打断思路的人。

## 30 秒上手

1. 安装并启动，按 **右 Alt**（或单击桌面悬浮球）打开工作台；
2. 按住说话，松开后文字出现在结果窗；
3. 需要的话改一改、挑同音词，再点「发送」把文字送进当前输入框。

## 它是怎么工作的（概览）

1. **唤醒**：右 Alt、悬浮球或鼠标侧键；
2. **识别**：音频在本机用离线模型识别，或发往你自己配置的在线接口；
3. **整理**：文字先进入结果窗，可编辑、同音词替换、AI 纠错；
4. **注入**：确认后通过系统输入通道写进当前焦点窗口，不移动鼠标、不抢焦点。

本仓库只发布安装包，不提供源代码。

## 和普通语音输入法有什么不同

- **先说后改**：识别结果先停在结果窗，不会边说边往文档里打字；
- **不抢焦点**：结果窗和悬浮球都是不激活窗口，弹出时不打断你正在做的事；
- **本地优先**：离线识别在本机完成，不保存音频；在线识别只发往你自己配置的服务；
- **可核查**：历史、收藏、文件中转站都在本地，随时可查可删。

## 系统要求

- Windows 10 1809（build 17763）及以上 / Windows 11，x64
- 无需管理员权限，默认安装到 `%LOCALAPPDATA%\Programs\VoiceInput`
- 离线识别需按需下载模型（226 MB ~ 941 MB）；也可改用在线识别，无需本地模型

## 主要功能

- **语音输入**：本地离线（sherpa-onnx：SenseVoice / Paraformer / Qwen3-ASR）或在线识别（OpenAI 兼容接口，自填 API Key）
- **唤醒方式**：右 Alt 开关工作台、单击悬浮球、鼠标侧键；结果窗不抢焦点，文字直接注入当前输入框
- **同音词候选**：选中文字后按读音给出同音/近音写法，支持一键替换
- **AI 纠错**：识别结果先顺一遍再上屏（可关闭）
- **常驻录音**：后台持续转写进历史，不保存任何音频文件
- **工作台能力**：历史、收藏、文件中转站、画板、符号面板、小键盘、按应用注入策略
- **本地优先**：无遥测、无广告、不上传历史与收藏

## 安装与首次运行

1. 下载并运行 `VoiceInput-Setup-vX.Y.Z.exe`（无需密码，直接安装）
2. 本程序未做代码签名，首次运行可能出现「Windows 已保护你的电脑」提示 → 点「更多信息」→「仍要运行」
3. 安装完成后启动，按 **右 Alt**（或单击悬浮球）打开工作台
4. 在设置里选择识别方式：离线需先下载模型；在线需填入你自己的 API Key（本软件不内置任何 Key）
