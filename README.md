# 输控工作台 (VoiceInput)

Windows 桌面常驻语音输入工作台：说完即得，先在结果窗里整理好，再一键送进任何输入框。

## 下载

- **[下载最新版本](../../releases/latest)**
- 安装包命名：`VoiceInput-Setup-vX.Y.Z.exe`
- **安装包为加密包**：安装时需要输入作者私下提供的安装密码（不在 Release 页公开）
- 下载后请用 Release 说明中的 SHA256 校验文件完整性

## 系统要求

- Windows 10 1809（build 17763）及以上 / Windows 11，x64
- 无需管理员权限，默认安装到 `%LOCALAPPDATA%\Programs\VoiceInput`
- 离线识别需按需下载模型（226 MB ~ 941 MB）；也可改用在线识别，无需本地模型

## 主要功能

- **语音输入**：本地离线（sherpa-onnx：SenseVoice / Paraformer / Qwen3-ASR）或在线识别（OpenAI 兼容接口，自填 API Key）
- **唤醒方式**：右 Alt 开关工作台、单击悬浮球、鼠标侧键；结果窗不抢焦点，文字直接注入当前输入框
- **同音词候选**：选中文字后按读音给出同音/近音写法，支持一键替换
- **AI 纠错**：识别结果先顺一遍再上屏（可关闭）
- **常驻录音**：后台持续转写进历史，不保存任何音频文件
- **工作台能力**：历史、收藏、文件中转站、画板、符号面板、小键盘、按应用注入策略
- **本地优先**：无遥测、无广告、不上传历史与收藏

## 安装与首次运行

1. 下载并运行 `VoiceInput-Setup-vX.Y.Z.exe`
2. 输入作者提供的安装密码（加密安装包）
3. 本程序未做代码签名，首次运行可能出现「Windows 已保护你的电脑」提示 → 点「更多信息」→「仍要运行」
4. 安装完成后启动，按 **右 Alt**（或单击悬浮球）打开工作台
5. 在设置里选择识别方式：离线需先下载模型；在线需填入你自己的 API Key（本软件不内置任何 Key）
